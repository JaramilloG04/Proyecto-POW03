Aprende, comparte y acompaña

La plataforma facilita encuentros de tutoría entre pares sin perder de vista la solidaridad, el cuidado y el acceso equitativo al conocimiento.

1. Crea tu perfil

Indica qué quieres aprender, las materias que puedes compartir y tus horarios disponibles.

2. Encuentra una tutoría

Busca acompañamiento por área de conocimiento y solicita un espacio que se ajuste a tu tiempo.

3. Construye comunidad

Mantén conversaciones simples con tu tutor o estudiante para preparar cada encuentro.
